# 📦 Sistema de Controle de Estoque

<p align="center">
  Sistema acadêmico de gerenciamento de estoque, desenvolvido em grupo utilizando a linguagem C e tecnologias web.
</p>

---

## 📖 Sobre o projeto

O **Sistema de Controle de Estoque** tem como objetivo desenvolver uma aplicação capaz de gerenciar produtos de maneira simples e organizada.

A lógica principal será implementada em **C**, utilizando **WebAssembly (WASM)** para permitir sua integração com uma interface web.

O projeto também tem como propósito colocar em prática conceitos de programação, estruturas de dados, desenvolvimento web e trabalho colaborativo com Git e GitHub.

## ⚙️ Tecnologias

| Tecnologia | Utilização |
|:--|:--|
| C | Lógica e operações do sistema |
| WebAssembly | Execução do código C no navegador |
| Emscripten | Compilação de C para WebAssembly |
| HTML | Estrutura da interface |
| CSS | Estilização da interface |
| JavaScript | Comunicação entre a interface e o WASM |
| Git e GitHub | Versionamento e colaboração |

## 🚀 Funcionalidades previstas

- [ ] Cadastrar produtos
- [ ] Listar produtos
- [ ] Consultar produtos
- [ ] Atualizar informações
- [ ] Excluir produtos
- [ ] Controlar quantidade em estoque
